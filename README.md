> **"Your Journey, Our Responsibility"**  
> Premier Himalayan tour packages, sanitized private taxi fleets, Volvo bus services, and verified luxury mountain stays.

---

## 🌟 Overview
**SafarSathi (Himachal Holiday)** is a modern, high-converting tour and travels platform built with **React 18, TypeScript, Tailwind CSS, and Vite**. Headquartered at **New Bus Stand, Tutikandi, Shimla (H.P.)**, the platform is designed to provide transparent itineraries, instant WhatsApp booking quotes, verified hill drivers, and handpicked stays across the Himalayas.

---

## 🚀 Key Features

- **Multi-Tab Smart Search & Booking Engine:**
  - 🏔️ **Tour Packages:** Filter by Destination, Season, and Group Size.
  - 🚖 **Taxi & Cabs:** Delhi, Chandigarh, Kalka, Shimla, Manali & Dharamshala outstation and local rentals (Dzire, Etios, Ertiga, Innova Crysta, Tempo Traveller).
  - 🏨 **Hotel Stays:** Verified properties in Shimla, Manali, Kasol, Amritsar, and Srinagar with real photo galleries.
  - 🚌 **Volvo Bus Services:** Daily luxury AC semi-sleeper overnight connections.

- **Detail-Centric Itineraries:**
  - Day-by-Day sequential breakdown (stay, meals, road route).
  - Transparent **Inclusions vs Exclusions** (No hidden green taxes or driver night allowances).

- **Real Hotel Photo Gallery (Lightbox):**
  - Over 90+ real property photos from partner hotels in Shimla, Manali, Amritsar, and Srinagar.

- **Direct Lead & WhatsApp Integration:**
  - Every booking and inquiry routes directly to WhatsApp (`+91 83519 87587`) with pre-filled travel details.
  - Sticky mobile action bar for one-tap calling and messaging.

## 💻 Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ajaynxt/safarsathi-himachal-holiday.git
   cd safarsathi-himachal-holiday
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
